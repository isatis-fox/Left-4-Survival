# How to install

1. Download BOTH VPKS from the latest release
2. Open your Left 4 Dead 2 game directory
3. Open the subdir "left4dead2"
4. Put the vpks in the "addons" directory
5. launch game, stonks


# Loading into a Map
Type the following into the dev console:
```
map ze_
OR
map zm_
```
It SHOULD show the Zombie Escape maps.
Some maps starts with "zm", which I am not changing, sorry.
